# Mechanical Rectifier [Apr-May 2025]  
A project that converts non-uniform input to a constant rotational output. My team of 3 and I worked on in Spring 2025. 
## Purpose & Requirements:
- Prototype and design a mechanical system that can convert random sinusoidal motion to constant rotational motion.  
- Connect components together using tolerances, whilst limiting the use of fasteners and eliminating the use of glue.   
- The system must fit within 180cm x 180cm optical breadboard.   
- The system must be able to be assembled and deconstructed within 3 minutes  
- Analyze output and create a technical report concluding the Mechanical Rectifier

## Contributions:  
- Modeled the exploded and unexploded CAD assembly
- Designed the base, cup, and base->cup connection of the fluid rotation system
- Designed the centrifugal governor legs and spline/linear bearing connector
- Created subsystem flow charts to display each component relations
- Organized a bill of materials
